# NotchBall

An NFL scoreboard that lives in your MacBook's notch.

**[Download the latest version](https://github.com/RayyanHai/notchball-releases/releases/latest/download/NotchBall.zip)** · macOS 15 or later, Apple silicon.

## First launch

1. Unzip and drag NotchBall to Applications.
2. Open it. When macOS says it could not verify NotchBall, click **Done**.
3. Open System Settings → Privacy & Security, scroll down, and click **Open Anyway**.
